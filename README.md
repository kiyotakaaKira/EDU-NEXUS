# CIT-Sentinel v2
AI-powered student retention platform for Chennai Institute of Technology

## Tech Stack
- Frontend: React 18 + Vite + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB Atlas
- AI: Ollama (Llama 3.2) + Claude API fallback

## Setup
### Frontend
```
npm install
npm run dev
```

### Backend
```
cd backend
npm install
node seed.js
npm run dev
```
